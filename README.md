# WHC Deploy — beveiligde toegang

Deze **publieke repository bevat alleen een statische doorverwijzing** naar de beveiligde WHC Deploy V1-applicatie op WHCapital. Geen applicatiebroncode, wachtwoorden, sleutels, gebruikersgegevens of interne API zijn hier gepubliceerd.

De actuele bestemming wordt bijgewerkt vanuit de geautoriseerde WHCapital-computer na verificatie van HTTPS en de Cloudflare-e-maillogin. De toegang tot WHC Deploy blijft beschermd door Cloudflare-e-mailverificatie voor de eigenaar.

Deze GitHub Pages-ingang is onafhankelijk van de bestaande Vercel-sites, het Namecheap-hoofddomein en MT5.
